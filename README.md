# Hexed Assets

Brand assets for the Hexed skill.

## Logo Files

### `hexed-logo.png`
- **Dimensions**: 1077x417px
- **Format**: PNG
- **Usage**: GitHub README, documentation, social media headers
- **Style**: Gritty, textured wordmark

### `hexed-sigil.png`
- **Dimensions**: 800x800px
- **Format**: PNG
- **Usage**: Original sigil artwork (crossed blades/X)
- **Style**: Edgy icon mark

### `hexed-icon.png`
- **Dimensions**: 512x512px
- **Format**: PNG
- **Usage**: **Claude Skills marketplace icon** (primary use)
- **Style**: Sigil optimized for square format

### `hexed-icon-256.png` & `hexed-icon-128.png`
- **Dimensions**: 256x256px, 128x128px
- **Format**: PNG
- **Usage**: Smaller displays, favicons, profile pictures
- **Style**: Scaled versions of sigil

## Usage Guidelines

- Logo should always be used on light backgrounds for optimal contrast
- Maintain aspect ratio when resizing
- Do not modify, rotate, or distort the logo
- Minimum display size: 200px width for logo, 64px for icon

## Brand Colors

The Hexed brand uses a monochromatic palette:
- Primary: Black (#000000)
- Secondary: White (#FFFFFF)
- Accent: Varies based on extracted colors from images
